# Stage 1: Confirm the Brief

## Start when

The Project Manager has supplied the approved brief, sitemap, assets, content status, references and known constraints.

## Designer task

Read the approved brief and record a concise Design Interpretation Note as a **markdown file in the client folder** (for example `design/design-interpretation-note.md`). This note confirms the Designer's understanding. It does not replace or rewrite the brief. **No Figma is needed at this stage** — the note is a written document, and the design work in Figma does not begin until a direction is chosen.

## Cowork prompt

Connect this Designer folder and the current client folder, then paste:

```text
Read the approved client brief and the supplied project materials.

Create a concise Design Interpretation Note, to save as a markdown file in the client folder
(`design-interpretation-note.md`), containing:
1. Primary business goal
2. Main audiences and their tasks
3. Priority conversion action
4. Required pages and sections
5. Intended visual tone
6. Brand rules and approaches to avoid
7. Available content and assets
8. Accessibility and project constraints
9. Approved references
10. Open questions for the Project Manager

Do not rewrite the brief, change scope or invent a missing answer. Identify any conflict
between the supplied materials. Ask no more than four questions at a time and wait for
my answers.

Show the proposed note before saving it. Do not begin visual directions yet.
```

## Finish when

- [ ] The Designer has checked the note against the approved brief
- [ ] Missing or conflicting information has been sent to the Project Manager
- [ ] Blocking questions are resolved
- [ ] The final Design Interpretation Note is saved as a markdown file in the client folder

## A note on Figma access

Stages 1 and 2 (confirming the brief and exploring visual directions in writing) need **no Figma**, so
they run on any seat. Figma is first used when you develop the chosen direction into concept frames at
the end of Stage 2, and again to build the design system in Stage 4. **Creating or editing in Figma needs
a Full or edit seat** — a Dev seat can inspect and read a file but cannot create or change one. Sort the
seat before Stage 2's concept frames.

Continue to `02_VISUAL_DIRECTION.md`.
