# Paste-in prompt: guided setup in Cowork

Copy the prompt below and paste it into Cowork. It guides the Designer through setup and checks each required item.

```text
I want to set up the DiscoverWeb design standard in Cowork. Guide me one step at a
time, wait for me after each step and use plain language.

1. First ask whether my organisation Owner has installed the DiscoverWeb
   design-standard skill for everyone.

2. If it is already installed, help me confirm it is enabled in Customize, then
   Skills. If it is not installed, guide me through Customize, Skills, +, Create
   skill, then Upload a skill. I will upload discoverweb-design-standard.zip.

3. Guide me through Customize, Plugins, then Browse plugins. Help me install and
   enable the Anthropic Design plugin and the Figma plugin from Anthropic & Partners.

4. Open the installed Figma plugin, select its Connectors tab and help me configure
   the included Figma connector. Confirm I signed in with the account used for
   agency work.

5. Ask me to provide a safe Figma practice file. Run a read-only DiscoverWeb design
   standard check. State what you inspected and what you could not verify. Do not
   change the Figma file.

Finish with SETUP READY or SETUP NOT READY and list any missing required item.

Use British and Australian English. Do not use em dashes, en dashes or emojis. Ask
me rather than assume. If something is unavailable on my account, say so plainly and
tell me who to ask.
```
