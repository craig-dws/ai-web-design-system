# Stage 3: DESIGN.md Pass A

## Start when

The client has approved one visual direction.

## Designer task

Create the first, narrative version of the client `DESIGN.md`. Pass A records the approved intent and explicit exclusions. Final Figma variables and component details are added later in Pass B.

Copy `reference/DESIGN.template.md` into the current client folder and rename the copy `DESIGN.md`.

## Cowork prompt

```text
Help me complete Pass A of the client DESIGN.md.

Read first:
- the approved client brief
- the approved visual direction and approval record
- reference/05_DESIGN_MD_GUIDE.md
- reference/DESIGN.template.md
- the current client DESIGN.md

Create a source summary showing what is known, missing or contradictory. Do not ask me
to repeat an answer already present in an approved source. Ask no more than four missing
questions at a time and wait for my answers.

For Pass A:
1. Record the purpose, intended audience response and approved design thesis.
2. Record concrete design principles and deliberate exclusions.
3. Describe the intended colour, typography, layout, imagery, shape and motion approach
   without presenting exploratory values as final.
4. Add concrete do and do not guidance.
5. Mark details that require the completed Figma system as [PENDING AFTER FIGMA].
6. Keep the status DRAFT.

Do not invent final tokens, component states or approval evidence. Show the complete
proposed DESIGN.md and wait for Designer confirmation before saving it.
```

## Finish when

- [ ] The approved design thesis is accurately recorded
- [ ] Principles and exclusions are concrete
- [ ] Unfinished system details are clearly marked
- [ ] No exploratory value is presented as approved
- [ ] The file status remains `DRAFT`

Continue to `04_CLIENT_DESIGN_SYSTEM.md`.
