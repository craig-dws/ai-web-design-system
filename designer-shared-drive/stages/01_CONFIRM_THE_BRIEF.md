# Stage 1: Confirm the Brief

## Start when

The Project Manager has supplied the approved brief, sitemap, assets, content status, references and known constraints.

## Designer task

Read the approved brief and record a concise Design Interpretation Note on the Figma cover page. This note confirms the Designer's understanding. It does not replace or rewrite the brief.

## Cowork prompt

Connect this Designer folder and the current client folder, then paste:

```text
Read the approved client brief and the supplied project materials.

Create a concise Design Interpretation Note for the Figma cover page containing:
1. Primary business goal
2. Main audiences and their tasks
3. Priority conversion action
4. Required pages and sections
5. Intended visual tone
6. Brand rules and approaches to avoid
7. Available content and assets
8. Accessibility and project constraints
9. Approved references
10. Open questions for the Project Manager

Do not rewrite the brief, change scope or invent a missing answer. Identify any conflict
between the supplied materials. Ask no more than four questions at a time and wait for
my answers.

Show the proposed note before saving it. Do not begin visual directions yet.
```

## Finish when

- [ ] The Designer has checked the note against the approved brief
- [ ] Missing or conflicting information has been sent to the Project Manager
- [ ] Blocking questions are resolved
- [ ] The final Design Interpretation Note is on the Figma cover page
